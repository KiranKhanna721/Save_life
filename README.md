# Save Life: Carbon Footprint Calculator

A Streamlit app that estimates a household's yearly carbon emissions.

## Inputs

- Diet (vegetarian or non-vegetarian) and average daily calories
- Number of family members
- Kilometres driven per year
- Household utilities (electricity, natural gas, fuel and so on)
- Total spending after utilities

The app combines these with simple emission factors to give an estimated carbon footprint.

## Getting started

```bash
pip install -r requirements.txt
streamlit run app.py
```
